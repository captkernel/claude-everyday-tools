# Wardrobe / Outfit-Planner App

> **Value:** Low &nbsp;|&nbsp; **Implementability:** Moderate

## What this is
A 'Clueless'-style digital closet: photograph your wardrobe, tag items, get outfit suggestions.

## Why it's worth building
A real, concrete app if you personally want it — the only non-Claude idea you kept. Vision auto-tagging of garments is a fun optional AI touch. No leverage on your Claude tooling, so purely a personal-interest build.

## What's here
A runnable, dependency-light build (Python stdlib only; data in a local JSON file):

| File | Purpose |
|------|---------|
| `wardrobe.py` | Core logic: `Garment` data model, `Wardrobe` store (add/list/remove, JSON-persisted), `suggest_outfit()`, and the optional `autotag()` vision stub. |
| `cli.py` | Tiny CLI: add / list / remove a garment, suggest an outfit, autotag (stub). |
| `test_wardrobe.py` | TDD test suite (17 tests) covering add/list/persist and the suggester rules. |
| `wardrobe.json` | Local data file (auto-created on first add; git-ignored). |

### Data model
A `Garment` has `id` (auto), `name`, `category` (`top` / `bottom` / `dress` / `shoes` / `outerwear`), `color`, and `tags`. Category/color/tags are normalized to lowercase; unknown categories are rejected.

### Outfit-suggester rules (simple & documented)
1. A valid outfit is **top + bottom + shoes** OR **dress + shoes** — never two tops, never a top with a dress.
2. Shoes are always required.
3. `occasion` filter: every garment must carry that occasion as a tag.
4. `weather`: `cold` may layer on outerwear; `hot` prefers a dress and skips outerwear.
5. Basic color sense: known clashing color pairs (e.g. red+pink) are avoided when a non-clashing alternative exists.

Suggestions are randomized for variety, but always satisfy the rules above. If no valid outfit exists, `NoOutfitError` is raised.

### Vision auto-tagging
`autotag(image_path) -> dict` is an intentional **stub** that returns the expected `{category, color, tags}` shape without any model or API key. Plug a vision model into `wardrobe.autotag()` to enable real photo tagging — nothing else needs to change.

## Usage
Run from the repo root. Examples (the CLI defaults to `./wardrobe.json` inside this folder):

```sh
# from projects/wardrobe-outfit-planner/
python cli.py add --name "White Tee" --category top --color white --tags casual,summer
python cli.py add --name "Blue Jeans" --category bottom --color blue --tags casual
python cli.py add --name "White Sneakers" --category shoes --color white --tags casual
python cli.py list
python cli.py list --category top
python cli.py suggest
python cli.py suggest --occasion formal --weather cold
python cli.py remove --id <id>
python cli.py autotag --image path/to/photo.jpg   # stub
```

### Run the tests
From the repo root:

```sh
.venv\Scripts\python.exe -m pytest projects\wardrobe-outfit-planner
```
